## 两条台账如何关联

跑步是内容来源，视频是跑步的记录。两条台账通过「视频序号 / 对应跑步日期」互相关联：

- 跑步明细中的「视频序号」列：标记当天是否产出视频，填入累计视频编号。
- 视频明细中的「对应跑步日期」列：回指该条视频拍摄于哪天跑步。

这样任意一天都能串起完整链条：跑了多远 → 拍了哪条视频 → 数据表现如何。

## 更新流程（与 WorkBuddy 协同）

1. 用户口述当日数据，或定期从跑步 App / 抖音导出记录。
2. WorkBuddy 写入对应月份的明细表，保持表格列结构不变。
3. 同步更新 `INDEX.md` 的累计统计与月度小计。
4. 一次提交写明「日期 + 变更内容」，推送到本仓库。
5. 新月份开始时，复制 `TEMPLATE.md` 为 `YYYY/MM_月份.md`。

## 数据边界（重要）

- 历史明细（2021-01 至 2026-11-22）**尚未录入**，当前仅记录用户口述的汇总基准。

- 本目录与仓库一致为 private；抖音账号数据对外发布前，先确认是否适合公开。
