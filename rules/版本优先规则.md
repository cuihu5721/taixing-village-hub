# 驻村工作日志版本优先规则

## 规则正文

同一日期在不同版本中重复出现、内容或措辞不同时，一律以**更新日期最晚（最新）的版本**为准。旧版只作沿革记录，不并列展示、不引用旧措辞。

今后记录、更新日志，以及由日志派生的数据和文档，都按此逻辑执行，始终只保留唯一主版本。

## 在 GitHub 中的落地方式

- 每次更新日志是一次独立提交（commit），自带时间戳与变更说明。
- 同一日期多次修改，最后一次提交即为主版本；历史提交保留在版本记录中，可随时回查，但不作为当前内容展示。
- 提交信息格式：`YYYY-MM-DD 更新：<变更摘要>`。
- 禁止在仓库中并存多个同名不同版本的日志文件（如「最终版」「修订版」）。
