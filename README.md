# 太兴村数据中枢

> 私有仓库。用于沉淀驻村工作日志、工作规则与村务知识，实现版本可追溯、变更可核对。

## 目录结构

| 路径 | 用途 |
| --- | --- |
| `log/2026/` | 驻村工作日志，按月分文件，唯一主版本 |
| `rules/` | 工作规则：版本优先、休息日填写、协同工作流 |
| `docs/` | 制度、流程、台账模板等村务知识文档 |
| `data/` | 脱敏后的结构化数据；人员土地明细留存本地，不上云 |

## 当前日志主版本

- 来源：`驻村工作日志（2026年度·自动换行版·11月23日更新·补录11月23日事项）.xlsx`
- 范围：2026-04-20 至 2026-11-23，共 218 天有效记录
- 表头：年月日 / 工作事项 / 总体要求 / 参加人员 / 完成情况 / 备注
- 说明：2026-11-24 至 12-31 为预填日期序列号，无工作事项，不计入有效日志

## 使用约定

1. 同一日期只保留一个主版本，以更新日期最晚者为准，旧版仅作沿革、不并列展示。
2. 每次更新通过 WorkBuddy 提交，提交信息写明「日期 + 变更内容」。
3. 法定休息日无具体事项时，仅在工作事项列填「休息」，其余列留空。
4. 本仓库为 private，含工作联系人信息，禁止转为公开或外传。
